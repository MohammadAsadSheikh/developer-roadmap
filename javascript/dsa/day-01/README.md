# Day 1 — DSA Practice

## Problems Solved

### 1. Two Sum

- **Pattern:** Hash Map
- **Approach:** Store previously visited numbers and their indices in a Map. For each number, calculate the complement and check whether it has already been visited.
- **Time Complexity:** O(n)
- **Space Complexity:** O(n)
- **Solution:** `01-two-sum.ts`

### 2. Valid Palindrome

- **Pattern:** String Manipulation
- **Approach:** Convert the string to lowercase, remove non-alphanumeric characters, reverse the normalized string, and compare both strings.
- **Time Complexity:** O(n)
- **Space Complexity:** O(n)
- **Solution:** `02-valid-palindrome.ts`

## Key Learnings

- Using a Map for efficient lookups.
- Understanding time and space complexity.
- Working with TypeScript function types.
- Normalizing and manipulating strings.
- Writing and testing reusable functions.
